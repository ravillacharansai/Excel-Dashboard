# HR Analytics Dashboard

## 📌 Project Overview

The HR Analytics Dashboard is an interactive data analytics project built using Microsoft Excel. It provides insights into employee attrition, workforce demographics, job roles, departments, and other HR metrics to help organizations understand employee trends and make informed decisions.

The dashboard uses Excel Pivot Tables, Charts, and KPI cards to visualize important HR data in a simple and interactive format.
